## Final Practical Assessment

**Task:** Conduct a network scanning assessment against an authorized isolated lab environment.

The student must:

- Identify active hosts.
- Perform TCP and UDP port scanning.
- Identify available services.
- Perform OS detection.
- Analyze network traffic using Wireshark.
- Save Nmap scan results.
- Prepare a technical scanning report.
