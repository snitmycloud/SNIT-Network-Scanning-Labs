
# Network Scanning Practical Labs

This directory contains hands-on exercises for the Scanning Phase in Ethical Hacking.

## Practical Labs

1. Scanning Fundamentals
2. Nmap Fundamentals
3. Host Discovery
4. TCP Port Scanning
5. UDP Port Scanning
6. Service and Version Detection
7. OS Detection
8. Firewall Analysis
9. IDS Detection
10. Scanning Report Generation

All practical exercises must be performed in an isolated lab or against explicitly authorized targets.
