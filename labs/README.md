# SNIT Network Scanning Labs

Welcome to the practical lab series of the SNIT Network Scanning & Nmap Training Program.

This section contains hands-on exercises designed to help students understand network scanning techniques, Nmap operations, service identification, host discovery, and scanning assessment.

## Practical Lab Index

| Lab No. | Lab Title | Main Topics |
|---|---|---|
| 01 | [Scanning Fundamentals](01_scanning_fundamentals/README.md) | Scanning concepts, objectives, lab setup |
| 02 | [Nmap Fundamentals](02_nmap_fundamentals/README.md) | Nmap commands, options, target specification |
| 03 | [TCP Port Scanning](03_tcp_port_scanning/README.md) | TCP SYN, TCP Connect, port states |
| 04 | [UDP Port Scanning](04_udp_port_scanning/README.md) | UDP scanning, response analysis |
| 05 | [Service & Version Detection](05_service_version_detection/README.md) | Service identification, banner grabbing |

| 07 | [Host Discovery & Network Scanning](07_host_discovery_network_scanning/README.md) | ICMP, TCP and ARP discovery |
| 08 | [Firewall Detection & IDS Awareness](08_firewall_detection_ids_awareness/README.md) | Firewall behavior, IDS monitoring |
| 09 | [Nmap Evasion Concepts & Traffic Analysis](09_nmap_evasion_traffic_analysis/README.md) | Timing profiles, packet analysis |
| 10 | [Scanning Assessment & Report Generation](10_scanning_assessment_report_generation/README.md) | Complete scanning assessment, reporting |

## Recommended Learning Sequence

Complete the labs in numerical order.

1. Understand scanning fundamentals.
2. Learn Nmap commands and scanning options.
3. Practice TCP and UDP scanning.
4. Identify services and operating systems.
5. Discover active hosts.
6. Understand firewall and IDS behavior.
7. Analyze scanning traffic.
8. Complete the final scanning assessment.

## Lab Requirements

- Kali Linux
- Nmap
- Wireshark
- Netcat
- VirtualBox or VMware
- An isolated vulnerable lab machine

## Student Submission

For each lab, students should maintain:

- Command execution records
- Screenshots of practical exercises
- Wireshark packet observations
- Scan output files
- Answers to assessment questions

## Important Notice

All exercises must be performed on systems owned by the student or explicitly authorized for testing. Use an isolated virtual lab for scanning exercises.
